# ComTrade – เว็บไซต์ร้านค้าขายคอมพิวเตอร์มือสอง

โครงงานวิชา CE306 (สถานะ: ทำแล้วประมาณ 50%)

## ทำแล้ว
- หน้าแรกและรายการสินค้า
- Interactive Filter (Fetch + Partial Render, จำลอง API)
- ตะกร้าและสรุปราคาแบบ Real-time

## ยังไม่ทำ
- Backend Node.js + REST API
- ฐานข้อมูล PostgreSQL/MySQL
- ระบบสมาชิก (JWT)
- หน้า Admin (CRUD)
- ระบบสั่งซื้อ

## วิธีรัน
เปิดโฟลเดอร์ใน VS Code แล้วคลิกขวาที่ `index.html` เลือก **Open with Live Server**
